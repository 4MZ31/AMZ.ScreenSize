# AMZ.ScreenSize 1.1.0

Des profils de format d’écran pour chaque jeu, avec détection des jeux installés.

## Nouveautés

- **Gérer / détecter…** : ajouter, modifier, désactiver ou supprimer un profil.
- **Jeux installés…** : détecter les installations Steam, Epic Games, GOG, Xbox accessibles et certaines installations déclarées dans Windows.
- Sélectionner les jeux à ajouter, leur attribuer un format, puis ajuster chaque profil séparément.
- Un format propre à chaque jeu et plusieurs noms de processus possibles par profil.
- Le premier jeu détecté garde la priorité. À sa fermeture, un autre jeu ouvert prend le relais ; après le dernier jeu, le format d’origine est restauré.
- Le profil Counter-Strike et les préférences existants sont conservés automatiquement.
- Les mises à jour attendent aussi la fermeture de l’éditeur de profils.

## Vérifications

78 assertions hors matériel, un cycle réel avec deux processus de jeu et restauration du format précédent, ainsi qu’une vérification de la détection sur des installations locales. Les fichiers de documentation utilisent uniquement des jeux fictifs.

La détection des exécutables reste indicative ; le bouton **Choisir un .exe…** permet de la corriger. Les installations protégées ou non déclarées peuvent nécessiter un ajout manuel.

## Télécharger

- **AMZ.ScreenSize.exe** : exécutable portable Windows.
- **AMZ.ScreenSize-v1.1.0-win.zip** : application et documentation illustrée.
- **SHA256SUMS.txt** : empreintes SHA-256 des fichiers.

Windows 10/11 64 bits, .NET Framework 4.8 ou supérieur. Le Samsung Odyssey G4 S27BG400EU / SAM727E en DisplayPort est le modèle vérifié. L’application change la taille d’image du moniteur, sans modifier la résolution Windows. L’exécutable n’est pas signé numériquement.
